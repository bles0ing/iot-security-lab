# 引脚定义表

## STM32 + AT24C02 + OLED 正常通信

| AT24C02 引脚 | 信号 | STM32 引脚 | 备注 |
|---|---|---|---|
| 1 (A0) | A0 | GND | 地址位，接地 = 0 |
| 2 (A1) | A1 | GND | 地址位，接地 = 0 |
| 3 (A2) | A2 | GND | 地址位，接地 = 0 |
| 4 (GND) | GND | GND | 共地 |
| 5 (SDA) | SDA | PB7 | I2C1_SDA，需 4.7kΩ 上拉到 3.3V |
| 6 (SCL) | SCL | PB6 | I2C1_SCL，需 4.7kΩ 上拉到 3.3V |
| 7 (WP) | WP | GND | 写保护，接地允许写入 |
| 8 (VCC) | VCC | 3.3V | 严禁接 5V |

> AT24C02 I2C 设备地址：0xA0（写）/ 0xA1（读）

## OLED（I2C 接口）

| OLED 引脚 | STM32 引脚 | 备注 |
|---|---|---|
| VCC | 3.3V | |
| GND | GND | |
| SCL | PB6 | 与 AT24C02 共线（I2C 总线） |
| SDA | PB7 | 与 AT24C02 共线（I2C 总线） |

> OLED I2C 设备地址：0x78（写）/ 0x79（读）

## CH341A + AT24C02 攻击场景

| AT24C02 引脚 | CH341A ZIF 座 | 备注 |
|---|---|---|
| 1 (A0) | GND | 地址位接地 |
| 2 (A1) | GND | 地址位接地 |
| 3 (A2) | GND | 地址位接地 |
| 4 (GND) | GND | 共地 |
| 5 (SDA) | SDA（ZIF 13） | 数据线 |
| 6 (SCL) | SCL（ZIF 14） | 时钟线 |
| 7 (WP) | GND | 写保护接地，允许写入 |
| 8 (VCC) | 3.3V（ZIF 16） | **跳线必须切到 3.3V** |

## 逻辑分析仪连接

| 探头 | 连接点 | 颜色标记 |
|---|---|---|
| CH0 | PB6（SCL） | 黄色 |
| CH1 | PB7（SDA） | 蓝色 |
| GND | STM32 GND | 黑色 |

> 采样率：24MHz，协议解码选 I2C

## 注意事项

- **AT24C02 是 3.3V 器件，严禁接 5V**
- SDA 和 SCL 必须各接一个 4.7kΩ 上拉电阻到 3.3V
- CH341A 电压跳线必须切到 3.3V 位置
- AT24C02 插入 ZIF 座时，1 脚（圆点/缺口标记）朝向手柄侧
- WP 引脚必须接地才能写入
